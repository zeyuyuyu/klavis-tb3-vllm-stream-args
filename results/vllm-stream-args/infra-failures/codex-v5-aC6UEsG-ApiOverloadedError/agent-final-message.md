I’ve isolated the core failure mode: most implementations assume one parser transition per decoder step, so a multi-token step can discover a name, arguments, and even the next call while returning only the first transition; later calls then diff against state that was never sent. Several also rescan the full accumulated output, making the [REDACTED]50k-character case quadratic. I’m replacing that pattern with an incremental JSON event scanner that can emit every transition found in one decoder delta and canonicalizes argument JSON as it arrives.
